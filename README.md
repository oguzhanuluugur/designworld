# Design World - Luxury Architecture Portfolio

A high-end, single-page portfolio website for Design World Architecture & Decoration firm.

## Tech Stack

- **Framework:** Next.js 14+ (App Router, TypeScript)
- **Styling:** Tailwind CSS
- **Animation:** Framer Motion
- **Slider:** Swiper.js

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure

```
designworld/
├── app/              # Next.js App Router
├── components/       # React components
├── public/           # Static assets
│   └── images/       # Image assets
│       ├── logo/     # Logo files
│       └── hero/     # Hero slider images
└── lib/              # Utilities and constants
```

## Logo Placement

Place your logo file(s) in: `/public/images/logo/`

Supported formats: PNG, SVG, WebP
